# 阅见序章 · Web 端设计系统（初版风格预测）

> 本文件是「阅见序章」小程序转 Web 的**唯一设计依据**。
> 任何页面在动手前先读本文件；如某页有特殊规则，另建 `pages/<页面名>.md`，其优先级高于本文件。
> 版本：v1.0（初版风格预测） | 依据：小程序 5 张界面截图 + ui-ux-pro-max 检索结果

## 2. 风格决策

### 2.1 采纳

- **骨架：Minimalism & Swiss Style** —— 几何栅格、大面积留白、高对比、无装饰，靠排版层级表达信息。
- **调性：Flat Design + Micro-interactions**（Productivity Tool 产品类型推荐）—— 点击即时反馈，不做拟物、不做软糯。
- **借鉴 Editorial Grid 的排版纪律** —— 只取栏宽与基线节奏，用于课表 7 列网格对齐。

### 2.2 驳回（含理由）

| 模板 | 驳回理由 |
|---|---|
| Neumorphism + 薰衣草紫 `#7C3AED` | 命中 wellness/冥想类场景；双侧柔和阴影在网格纸背景上会浑浊；skill 标记可访问性风险 `high` |
| Academic 衬线字体（Crimson Pro / EB Garamond） | 衬线会让“工具产品”变成“学术出版物”，与截图紧凑黑体标题冲突 |
| 宝蓝 `#1E40AF` 主色 | 品牌绿是原型的识别符号，不可替换 |
| 深海军蓝 `#1E3A5F` 主色 | 偏论文出版气质，缺乏校园活力 |

### 2.3 借用但改造

- **LMS 配色结构**：深青绿主色 + 极浅带色底 + muted 三层灰 → 色值改为原型深绿与米绿底。
- **Atkinson Hyperlegible 的可读性理念**：正文字号不过小、字距不挤，但不采用该字体本身。

## 3. Token 三层结构

### 3.1 Primitive 原始色板

```css
--green-900: #0B4F3B;
--green-700: #0F6B4F;
--green-500: #1E7A5A;
--green-200: #BFDCCD;
--green-100: #DCEBE3;
--green-050: #EEF4EF;
--paper-000: #FFFFFF;
--paper-050: #F7F8F4;
--paper-100: #F4F6F0;
--ink-900:   #111814;
--ink-600:   #67706B;
--ink-400:   #8A938E;
--amber-500: #C98A12;
--violet-500:#7C6BC4;
--red-600:   #C0392B;
```

### 3.2 Semantic 语义层

| Token | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#F4F6F0` + 24px 网格线 `rgba(15,107,79,.06)` | 页面底色 |
| `--color-surface` | `#FFFFFF` | 卡片 |
| `--color-brand` | `#0F6B4F` | 双色标题后半句、选中态、图表数据 |
| `--color-brand-deep` | `#0B4F3B` | 按下态、深色底块 |
| `--color-brand-soft` | `#DCEBE3` | 标签底、FAB 光晕 |
| `--color-text` | `#111814` | 标题前半句、核心数字 |
| `--color-text-secondary` | `#67706B` | 说明文案、正文辅助信息 |
| `--color-text-tertiary` | `#8A938E` | 仅装饰性提示，**禁止用于正文** |
| `--color-border` | `rgba(15,107,79,.12)` | 卡片内分隔线 |

### 3.3 状态色（座位图专用）

| 状态 | 色值 | 必须附加的非颜色标识 |
|---|---|---|
| 在线 | `#1E7A5A` | 实心方块 |
| 暂时离开 | `#C98A12` | 实心方块 + 右上角缺口 |
| 离开 | `#8A938E` | 空心方块 |
| 预约中 | `#7C6BC4` | 实心方块 + 斜线纹理 |

### 3.4 对比度实测（WCAG AA 校验结果）

| 组合 | 比值 | 判定 |
|---|---|---|
| `#0F6B4F` on `#FFFFFF` | 6.49:1 | 通过 |
| `#0F6B4F` on `#F4F6F0` | 5.96:1 | 通过 |
| `#67706B` on `#FFFFFF` | 5.11:1 | 通过 |
| `#67706B` on `#F4F6F0` | 4.70:1 | 通过 |
| `#FFFFFF` on `#0F6B4F` | 6.49:1 | 通过 |
| `#111814` on `#FFFFFF` | 18.03:1 | 通过 |
| `#8A938E` on `#FFFFFF` | 3.16:1 | **不通过**，禁止用于正文 |

> 关键修正：原型中较淡的辅助灰 `#8A938E` 在 Web 上不满足 AA，全站说明文字统一改用 `#67706B`。
> 想保留轻盈感，用「字号更大 + 字重更轻」替代「颜色更淡」。

## 4. 字体规范

### 4.1 字体族

```css
--font-sans: "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
--font-display: "Outfit", var(--font-sans);
--font-num: "Outfit", "Fira Sans", ui-monospace, sans-serif;
```

- 中文字体：**人文无衬线**，方正、字腔适中。
- 数字与拉丁：**Outfit 几何无衬线**，圆形 `o`、单层 `a`、笔画等宽。
- 全站**禁止衬线体**。

### 4.2 字号层级

| 级别 | 字号 / 行高 / 字重 | 字距 | 用途 |
|---|---|---|---|
| Display | 40 / 1.1 / 600 | -0.02em | 核心数据（0.0 小时、340） |
| H1 | 22 / 1.3 / 700 | -0.02em | 页面主标题 |
| H2 | 17 / 1.4 / 600 | -0.01em | 卡片标题 |
| Body | 14 / 1.6 / 400 | 0 | 正文 |
| Caption | 12.5 / 1.5 / 400 | 0 | 辅助说明 |
| Overline | 11 / 1.4 / 600 | 0.08em | `STUDY STATS` 类小标签，大写 |

- 所有数字加 `font-variant-numeric: tabular-nums`，防止数值变化时布局抖动。

### 4.3 双色标题（品牌符号，不可省略）

```
我的账号（--color-text） + 与学习足迹（--color-brand）
```
- 两段之间不加空格，共享同一基线。
- 标题下方装饰线：宽 40px、高 2px、色 `#0F6B4F`、圆角 1px、距离标题 8px。

## 5. 间距与栅格

| Token | 值 |
|---|---|
| `--space-1` ~ `--space-12` | 4 / 8 / 12 / 16 / 24 / 32 / 48 |

- 基准栅格 4px。
- 手机画幅：390 × 844，左右留白 16px。
- 卡片间距 12px，卡片内 padding 16px，卡内元素间距 8px。
- 一律使用 `gap` 控制间距，**禁止逐项 margin**。
- 页面背景网格：24px × 24px，线色 `rgba(15,107,79,.06)`。

## 7. 组件规范

### 7.1 TitleBlock 双色标题块
- 结构：H1 双色文本 + 副标题（Caption，`--color-text-secondary`）+ 40×2px 绿线。

### 7.2 DataCard 数据卡
- 20px 圆角、16px 内边距、白底、`--shadow-card`。
- 标题行左侧为 H2，右侧为操作文字（品牌绿，13px/500）。

### 7.3 StatNumber 核心数字
- Display 字号 + `tabular-nums`，单位文字用 Caption 跟在数字右下。

### 7.4 MiniBarChart 七日柱状图
- 纯 CSS 柱状，柱宽 6px、圆角 3px、柱间距 8px。
- 柱体色 `#1E7A5A`，当日柱体 `#0F6B4F`。
- 每根柱必须有 `aria-label` 标注「周X X.X 小时」，不可仅靠颜色表达。
- 柱下方为星期文字，Caption 字号。

### 7.5 SeatMap 座位平面图
- 网格化排布，F2 / F3 / F4 分区，分区之间留 16px 通道。
- 座位视觉尺寸 16px，**可点击热区扩展至 24×24**（Web）/ 44×44（移动画幅）。
- 相邻座位逻辑间距 ≥ 8px。
- 状态必须同时用「颜色 + 形状/纹理」双编码，并提供带文字说明的图例。
- 顶部标注「最深处」「靠窗」等物理方位标签。

### 7.6 TabBar 底部导航
- 5 项：首页 / 图书馆座位 / 小阅 / 课表 / 我的。
- 中央「小阅」为凸起 FAB，直径 56px，带 `--shadow-fab` 绿色光晕。
- 选中态：图标与文字均为 `#0F6B4F`；未选中为 `#8A938E`（图标）+ `#67706B`（文字）。
- 每项热区 ≥ 44×44。

### 7.7 ChatDrawer AI 对话层
- 欢迎气泡 + 复合输入条（`+` 添加 / 输入框 / 发送键）。
- 输入框高度 44px，圆角 999px。
- 用户气泡用品牌绿底白字，助手气泡白底深色字。

### 7.8 EmptyState 空状态
- 三段式：主文案（H2）+ 关怀句（Caption）+ 引导动作（文本按钮）。
- 例：`还没有课表` / `点右上角「+ 添加」，可手动录入或从课表截图一键识别`。

### 7.9 WeekStrip 周条
- 7 列，当前日高亮：绿底 + 白字 + 圆角 12px。
- 日期数字用 `tabular-nums`。

## 8. 交互与动效

| 项 | 规范 |
|---|---|
| 过渡时长 | 悬停 / 按压 150–200ms；卡片进场 280ms |
| 缓动 | `cubic-bezier(.22,.61,.36,1)`（等价 power1.out） |
| 卡片进场 | `opacity 0→1` + `translateY(8px→0)`，`stagger 30ms` |
| 焦点态 | `:focus-visible { outline: 2px solid #0F6B4F; outline-offset: 2px; }`，**禁止 `outline: none`** |
| 减少动效 | 全部动画包在 `@media (prefers-reduced-motion: no-preference)` 内 |
| 点击反馈 | 按下时 `scale(.97)` + 背景加深至 `--green-900` |
| 触控热区 | Web ≥ 24 CSS px，移动画幅 ≥ 44×44 |
| 相邻热区间距 | ≥ 8px |

## 9. 图标

- 库：**Phosphor Icons（Outline）**，统一线性风格。
- 图标一律内联 SVG，**禁止用 emoji 充当图标**。
- 尺寸：导航 22px，卡内 18px，按钮内 16px；线宽保持库默认。
- 装饰性图标加 `aria-hidden="true"`；交互性图标必须提供可访问名称。

---

## 10. 反模式清单（严禁）

- ❌ 使用衬线字体
- ❌ 用 `#8A938E` 作为正文或说明文字颜色
- ❌ 用 emoji 当图标
- ❌ 座位状态仅靠颜色区分
- ❌ 移除 focus 轮廓
- ❌ 重阴影 / 毛玻璃 / 拟物凸起
- ❌ 卡片内混用 `margin-bottom` 堆叠间距
- ❌ 动效时长全站统一一个值（应有层级差异）
- ❌ 把品牌绿替换为蓝、紫或任何非原型色
